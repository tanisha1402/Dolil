# Synthetic demo documents
Invented for demonstration. They are NOT real records and must never be presented as authentic.
Paste each file's text (or upload the .txt) into the matching document box under "Read this document with AI".
They contain the same planted problems as the built-in sample case: the plot number differs (1245 vs 1254) and the
deed sells 10 decimal while the khatian share works out to 6 decimal (24 x 1/4). Because the deed's seller name is in
Bangla and the khatian's owner is in English, Dolil also shows a "names are in different scripts" note.
